# Bank Management System

A secure and user-friendly Bank Management System built using Java Swing and MySQL. It automates core banking operations.

## Features
- Account Creation (Signup)
- Login System
- Deposit & Withdrawal
- Fast Cash
- Balance Enquiry & Mini Statement
- Pin Change

## Tech Stack
- Java (Swing, AWT)
- MySQL
- NetBeans IDE

## How to Run
1. Open in NetBeans
2. Create database `bankSystem` in MySQL
3. Run Login.java
